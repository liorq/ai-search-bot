# ai-visibility — מי מורשה להיכנס, ומה יש שם לצטט

שתי החלטות שנוטות להתערבב, והסקיל שומר אותן נפרדות:

- **להיות מאומן עליך** — GPTBot, ClaudeBot, Google-Extended, Applebot-Extended.
- **להיות מצוטט על ידיך** — OAI-SearchBot, ChatGPT-User, Claude-SearchBot,
  PerplexityBot, Bingbot.

הן נוסעות תחת שמות סוכן שונים. חסימה גורפת של "בוטים של AI" חוסמת בדרך כלל את
הקבוצה השנייה — זו שמחזירה תנועה — ולא משיגה את מה שרצו.

**הסקיל לא ממליץ מה לבחור.** זו החלטה של בעל האתר, והוא מציג אותה כהחלטה.

## תהליך העבודה

```bash
python scripts/ai_visibility.py --self-check --client example.com
python scripts/ai_visibility.py --client example.com --max-pages 15
```

קריאה בלבד: `robots.txt`, `llms.txt` ומדגם דפים, בקצב מנומס. לא נדרש מפתח ולא
עולה כסף.

## מה נבדק

| | |
|---|---|
| הרשאות | כל סוכן בנפרד, מול `robots.txt` — מה מורשה ומה נחסם |
| `llms.txt` | קיים בשורש? דף 404 שמחזיר HTML לא נחשב |
| מבנה לציטוט | כותרת שאלה שאחריה תשובה ישירה, וסכמה שמסמנת מה זה |

**תשובה ישירה** היא 40–60 מילים אחרי הכותרת. ארוך יותר — המנוע מסכם בעצמו,
ואז הוא מצטט ניסוח שלא כתבת.

## מדידה: האם באמת מצטטים אותך

הסקיל בודק את **המוכנות**, לא את התוצאה. למדוד אזכורים בפועל אפשר דרך
DataForSEO — הכלים `ai_opt_llm_ment_*` ו-`ai_optimization_llm_response`.
זו קריאה בתשלום, והעלות נרשמת ומדווחת בסוף ההרצה.

## מה הסקיל לא עושה

- **לא עורך את האתר.** ההמלצות עוברות ל-`onpage-optimizer`, שם יש גיבוי ואישור.
- **לא משנה `robots.txt`.** זו החלטה, לא תקלה.
- **לא מבטיח ציטוט.** אין דרך לגרום למנוע לצטט; אפשר רק לוודא שהוא מורשה
  להיכנס ושיש לו מה לקחת.
