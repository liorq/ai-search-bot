# clarity-gsc — איך הגיעו, ומה עשו אחר כך

Search Console נגמר בקליק. Clarity מתחיל אחריו.

דף במיקום 4 עם 300 קליקים ו-40% קליקים מתים הוא בעיה אחרת לגמרי מדף במיקום 40
בלי אף קליק. שניהם "לא מביאים לידים", ורק אחד מהם שווה את זמנך השבוע.

## מה מחייב לדעת לפני שמשתמשים

**Clarity זוכר שלושה ימים.** נמדד מול ה-API, לא נלקח מתיעוד: בקשה ל-3 ימים
עובדת, בקשה ל-4 מחזירה שגיאה. המכסה היומית נגמרת אחרי כעשר קריאות ואז כל בקשה
נדחית.

לכן **ההיסטוריה היא משהו ששומרים, לא משהו ששואלים**. המשימה המתוזמנת מצלמת
יום ביום, ויום שלא צולם — אבד. הסקיל לא ממציא אותו ולא מקצר את החלון בשקט.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_clarity_timer.ps1 -Client example.com
```

המשימה רצה יומית, משלימה ימים שהוחמצו כשהמחשב היה כבוי כל עוד הם עדיין בטווח,
לא מבקשת פעמיים יום שכבר יש, ומקפיצה התראת Windows כשהיא נכשלת.

**טוקן לכל פרויקט.** ב-Clarity: Settings ← Data Export ← Generate new API token,
ואז `CLARITY_API_TOKEN` ב-`~/.claude/seo/.env`. טוקן אחד משרת פרויקט אחד.

## תהליך העבודה

```bash
python scripts/clarity_gsc.py --self-check --client example.com
python scripts/clarity_gsc.py --client example.com
```

`--self-check` אומר אם יש נכס, יש צילומים, וכמה ימים חסרים. הרצה בלי צילומים
עוצרת במקום להחזיר דוח ריק.

## מה יוצא

ארבע קבוצות, לפי תנועה מול התנהגות:

| | החוויה תקינה | המבקרים נתקעים |
|---|---|---|
| **מביא תנועה** | ✅ אל תיגע — זה המודל לשאר | 🔥 ההזדמנות הגדולה ביותר |
| **אין תנועה** | 👻 בעיית חשיפה, לא בעיית דף | 🤏 אין מספיק נתונים |

"מביא תנועה" הוא 5 קליקים ומעלה. "נתקעים" הוא רבע אות חיכוך לסשן ומעלה —
קליק מת, קליק זעם או חזרה מיידית. סשנים של בוטים מנוכים.

דף ש-Clarity לא ראה **לא מופיע בדוח**. היעדר נתון אינו עדות לחוויה טובה.

## מה הסקיל לא עושה

- **לא משנה כלום באתר.** הוא מצביע על דף ואומר לפתוח את ההקלטות שלו.
- **לא מנחש למה נתקעו.** קליק מת הוא סימן שמשהו נראה לחיץ ואינו; מה בדיוק — זה
  מה שההקלטה מראה ודוח לא.
- **לא מייחס המרות.** שאילתות, דפי נחיתה והמרות הן שלוש שכבות נפרדות.

## כשהתמונה חלקית

חסרים ימים — הסקיל אומר זאת בראש הדוח, לפני הממצאים. "לא נמצאו בעיות" על יום
אחד שמור זו אמירה על הנתונים, לא על האתר.
