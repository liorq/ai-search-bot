# 5 · UTM לקישור שבכרטיס

## ✅ בדיקה 5, חלק שני — מקור התנועה מ-GBP **לא** שורד

**הקישור בכרטיס היום:** `https://www.sass-srq.com/` — **בלי פרמטרים.**

מה שקורה בפועל: 25 הקליקים מהכרטיס נוחתים באתר ונרשמים ב-GA4 כ-
`google / organic`, **מעורבבים עם החיפוש האורגני הרגיל.** אין דרך להפריד
אותם. וברגע שההזמנה עוברת ל-iframe בדומיין אחר, גם מה שנשאר מהייחוס נשבר:
האירוע מגיע מהשרת של Acuity ב-Measurement Protocol, ולא מהדפדפן.

**כלומר היום אי אפשר לענות על "כמה הזמנות הגיעו מהכרטיס בגוגל".**

**הפעולה:** לשנות את הקישור בכרטיס ל-

```
https://www.sass-srq.com/?utm_source=google&utm_medium=organic&utm_campaign=gbp
```

**למה דווקא `utm_medium=organic`:** הוא משאיר את התנועה בערוץ Organic Search,
שם היא שייכת — זו תנועה לא ממומנת מגוגל — ובו בזמן מאפשר לבודד אותה לפי
`utm_campaign=gbp`. ‏`utm_medium=referral` היה מזיז אותה לערוץ אחר ומעוות
את ההשוואה ההיסטורית.

**אזהרה הוגנת:** ה-UTM גלוי בשורת הכתובת. חלק מבעלי העסקים לא אוהבים את זה.
וזה **שינוי בכרטיס** — לא אבצע אותו.

**מדד:** ב-18.10, דוח GA4 לפי `session_campaign = gbp` מראה מספר שאפשר להשוות
ל-25 קליקים שהכרטיס מדווח. פער גדול בין השניים הוא עצמו ממצא.
**ודאות: גבוהה** שההפרדה תעבוד. נמוכה לגבי גודל המספר.
