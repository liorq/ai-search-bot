# מפת טריגרים

נכתב **לפני** הסקיל הראשון. עם 22 סקילים שכולם עוסקים ב-SEO ורובם בעברית, הסכנה הגדולה
היא שקלוד יטען את הסקיל הלא נכון. המסמך הזה הוא המקור היחיד לאמת לגבי מי נטען מתי.

## החוק

לכל סקיל יש **עוגן ייחודי** — ביטוי שמופיע ב-`description` שלו ובשום סקיל אחר. ביטויים
משותפים (`SEO`, `קידום`, `גוגל`, `אתר`, `דוח`) לא מספיקים לבד לטעינת אף סקיל, ולכן הם
תמיד מופיעים לצד עוגן.

לפני הוספת סקיל חדש: לחפש את העוגנים המוצעים בטבלה. חפיפה = לבחור עוגן אחר.

---

## הסקילים הקיימים — נוסח מעודכן

ארבעה סקילים כבר מותקנים. התיאורים שלהם צריכים חידוד כדי שלא יבלעו טריגרים של החדשים.

| סקיל | עוגנים ייחודיים | מה **להסיר** מהתיאור |
|---|---|---|
| `gsc-crawl-checker` | sitemap · לא נסרק · לא מאונדקס · request indexing · URL Inspection · כיסוי | — (יורחב ל-IndexNow ו-Bing בשדרוג) |
| `keyword-research` | מחקר מילות מפתח · נפח חיפוש · וריאציות גיאוגרפיות · על מה לכתוב | `SEO keywords` לבדו — בולע את `topic-cluster` |
| `seo-monthly-report` | דוח חודשי ללקוח · סיכום חודשי · עדכון ללקוח · מה עשינו | `דוח SEO` לבדו — בולע את `seo-audit-report` |
| `semrush-keyword-gap` | keyword gap · רשימת דומיינים · KD · מיזוג CSV | `מתחרים` לבדו — בולע 4 סקילים |

**שתי ההפרדות הקריטיות:**

- `seo-monthly-report` = **ללקוח**, מה עשינו, חם ומשכנע.
  `seo-audit-report` = **לצוות**, מה לתקן, טכני ומדורג. מילת המפתח המבדילה: *חודשי* מול *אודיט*.
- `keyword-research` = מוצא מילים מאפס.
  `topic-cluster` = **מארגן** מילים קיימות למבנה. המבדיל: *מחקר* מול *קלסטר/מבנה/פילר*.

## ההתנגשויות שדורשות תשומת לב מיוחדת

ארבע נבדקות ידנית בכל הוספת סקיל:

| הזוג | ההבדל | איך הסקיל מפריד |
|---|---|---|
| `content-decay` ↔ `algorithm-update-watch` | דעיכה הדרגתית מול צניחה חדה סביב תאריך עדכון | `content-decay` דורש חלון של 90 יום+; `algorithm-update-watch` דורש אזכור עדכון או תאריך |
| `internal-anchors` ↔ `link-gap-prospector` | פנימי מול חיצוני | שניהם חייבים לשאת "פנימי" או "חיצוני/מתחרים" במפורש |
| `ctr-titles` ↔ `onpage-optimizer` | טייטל ומטא מול גוף הדף | `ctr-titles` נטען רק עם CTR / טייטל / מטא / הופעות |
| `seo-monthly-report` ↔ `seo-audit-report` | ללקוח מול לצוות | *חודשי/ללקוח* מול *אודיט/טכני/תוכנית עבודה* |

## תבנית ה-description

לפי הנוסחה שכבר עובדת בסקילים הקיימים:

```
1. משפט: מה הסקיל עושה + באיזו טכנולוגיה
2. משפט: מה הוא מפיק
3. "השתמש בסקיל הזה בכל פעם שמשתמש מזכיר:" + העוגנים מהטבלה למעלה
4. "גם אם המשתמש אומר בקיצור \"<דוגמה אמיתית>\" — הסקיל הזה צריך להיטען."
```
